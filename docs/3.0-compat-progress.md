## What's working as of M3 (2026-05-20)

End-to-end:
- `import sys` (cmodule path), `sys.version`, `sys.maxsize`, `sys.platform`
- `import mymodule` (single .py file on sys.path)
- `import pkg`, `import pkg.sub`, `import pkg.sub as alias` (packages)
- `from pkg.sub import x as y`, `from . import sib` (relative imports)
- `from pkg import sub` (submodule fallback when `sub` isn't an attribute)
- `from foo import *` (with `__all__` if present, else public names)
- Module isolation: imported-module functions see their own module's
  globals plus builtins, NOT main script's globals
- Circular imports complete without infinite-loop; partial-module
  attribute access during cycles is supported via Frame::module_idx
- ImportError on missing module / missing name, catchable in user code

Demonstration script: `tests/import_demo.py`.

## How this page is generated

## How to read the headline

The headline number is **`passed / total`**, where `total` is every file
matching `test_*.py` in `vendor/cpython-3.0/Lib/test/`. Skipped tests count
against `total` but in favor of nothing — a skip is *not* a pass. The skip
list represents capability we have explicitly deferred, and the goal is for
that list to shrink (or at least be fully justified) by the time we declare
3.0.1 compatibility at milestone **M10**.

## How to read the headline

The headline number is **`passed / total`**, where `total` is every file
matching `test_*.py` in `vendor/cpython-3.0/Lib/test/`. Skipped tests count
against `total` but in favor of nothing — a skip is *not* a pass. The skip
list represents capability we have explicitly deferred, and the goal is for
that list to shrink (or at least be fully justified) by the time we declare
3.0.1 compatibility at milestone **M10**.
